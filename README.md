# 📦 Telegram Bot Shop (Python + Aiogram)

Телеграм-бот для продажи цифровых товаров, реализованный с использованием **Aiogram 3**, **SQLAlchemy 2**, **Aiosqlite**
, **Alembic**, **Pydantic**

## ⚙️ Функционал

### Пользователь:

- `/start` — приветствие и регистрация.
- Просмотр каталога категорий и товаров.
- Доступ к купленному товару.
- История покупок.

### Администратор:

- Просмотр статистики.
- Добавление/удаление товаров.
- Получение уведомлений о покупках.

---

## 🗂️ Структура проекта

BOT_PROJECT/
├── app/
│ ├── admin/ # Админская логика и FSM
│ ├── user/ # Пользовательская логика
│ ├── DAO/ # Работа с базой данных (ORM)
│ ├── config.py # Конфигурации и настройки
│ └── main.py # Запуск бота
├── data/ # Файлы и база данных
├── .env # Переменные окружения
├── requirements.txt # Зависимости
└── alembic/ # Миграции базы данных



---

## ⚙️ Настройка

Создайте файл .env в корне проекта:

BOT_TOKEN=<ваш_токен_бота>
ADMIN_IDS=[]


---

## 📦 Миграции

Примените миграции Alembic:

- alembic upgrade head

## ▶️ Запуск бота

- python bot/main.py
  Пользователь:
  /start — регистрация и меню.

---

- Каталог:

    - Вывод категорий.

    - Просмотр товаров в категории.

---

- Покупка:

    - Сохранение покупки в БД.

    - Отправка товара пользователю.

    - Информация о магазине и история покупок.\

---

- Администратор:
    -   /admin — доступ к админ-панели.

    - Добавление товара (через FSM).
       
    - Удаление товара.

    - Просмотр статистики.
  
    - Получение уведомлений о покупках.
